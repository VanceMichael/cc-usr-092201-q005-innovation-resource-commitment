# 科创资源承诺兑现

记录科创项目资源缺口、服务承诺和兑现结果。

## 资料范围

领域资料位于 `fixtures/domain.json`，结构约定见 `contracts/domain.schema.json`。当前记录类型包括项目缺口、资源目录、服务承诺、容量占用、履约回执、转化结果，状态示例为待匹配 → 已承诺 → 已排期 → 履约中 → 部分完成 → 已核验。这些样例使用虚构标识，不含真实个人资料、账号或连接凭据。

已整理的业务事实：

- 路演平台连接政企单位、创投机构和创业校友
- 服务覆盖项目打磨、资源对接和产业落地
- 常态化交流旨在推动科研成果转化

## 本地校验

项目自带的测试会读取样例并检查领域标识、版本、记录类型、流程状态和事实说明。后续服务应继续兼容这份公开资料约定。
